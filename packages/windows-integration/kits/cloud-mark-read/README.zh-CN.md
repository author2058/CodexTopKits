# Mark cloud tasks read

[English](README.md) | 简体中文

在底部工具栏添加按钮，用于清理云端任务的未读标记。

在 **插件** 中启用 `footer` 和 `cloud-mark-read`，再选择 **重启插件宿主**。点击底栏的信封按钮，将当前云端未读任务标记为已读。未读数量归零后，按钮仍可使用。如果操作报告连接错误，可在管理页面查看详情。

需要 Core 0.3.39 或更高版本，以及 `footer` 0.1 系列中的 0.1.1 或更高版本。
