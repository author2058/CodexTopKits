# Mark cloud tasks read

English | [简体中文](README.zh-CN.md)

Adds a bottom-toolbar button to clear unread indicators for cloud tasks.

## Use

Enable `footer` and `cloud-mark-read` in **Kits**, then select **Restart Kit host**. Select the envelope button in the bottom toolbar to mark the current cloud unread tasks as read. The button remains available after the unread count reaches zero. If the action reports a connection error, check the manager for details.

Requires Core 0.3.39 or later and `footer` 0.1.1 or later in the 0.1 series.
