# Manager entry

English | [简体中文](README.zh-CN.md)

Adds a settings button to the right side of the [footer](../footer/README.md). Click it to open the local manager for the current Toolkit session. A red badge shows the active error count. Opening the manager acknowledges the current errors and restores the gear icon; when a new error occurs, the badge shows the total number of active errors.

Enable `manager-entry` and `footer` in **Kits**, then choose **Restart Kit host**. The button follows the manager's current address and language. Requires Core 0.3.39 or later and `footer` 0.1.6 or a compatible later version.
