# Footer

[English](README.md) | 简体中文

在 Codex 底部添加工具栏，分为左、中、右三个区域，中间区域弹性填充。工具栏会预留自身高度，聊天内容保持在其上方显示。

在管理器的 **插件** 页启用 `footer` 和需要显示的底栏功能，再点击 **重启插件宿主**。[周用量](../../../chat-enhancements/kits/weekly-usage/README.zh-CN.md)、[窗口标签](../../../windows-integration/kits/window-tabs/README.zh-CN.md)、[预约睡眠](../../../windows-integration/kits/auto-sleep/README.zh-CN.md)、[云端已读](../../../windows-integration/kits/cloud-mark-read/README.zh-CN.md)和[设置按钮](../manager-entry/README.zh-CN.md)分别提供各自的工具栏内容。

需要 Core 0.3.39 或更高版本。Kit 开发者可通过 [Kit API](../../docs/features.md)向 `left`、`center`、`right` 区域添加内容。
