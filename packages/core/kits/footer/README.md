# Footer

[English](#footer) | [简体中文](#简体中文)

Adds a bottom toolbar to Codex with left, flexible center and right areas. The toolbar reserves its own space so conversation content remains accessible above it.

## Use

Enable `footer` in **Kits**, together with the toolbar features to display, then choose **Restart Kit host**. [Weekly usage](../../../chat-enhancements/kits/weekly-usage/README.md), [window tabs](../../../windows-integration/kits/window-tabs/README.md), [sleep scheduling](../../../windows-integration/kits/auto-sleep/README.md), [cloud read controls](../../../windows-integration/kits/cloud-mark-read/README.md) and the [settings button](../manager-entry/README.md) each add their own toolbar content.

Requires Core 0.3.39 or later. Kit authors can use the toolbar's `left`, `center` and `right` slots through the [Kit API](../../docs/features.md).

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

在 Codex 底部添加工具栏，分为左、中、右三个区域，中间区域弹性填充。工具栏会预留自身高度，聊天内容保持在其上方显示。

在管理器的 **插件** 页启用 `footer` 和需要显示的底栏功能，再点击 **重启插件宿主**。[周用量](../../../chat-enhancements/kits/weekly-usage/README.md#简体中文)、[窗口标签](../../../windows-integration/kits/window-tabs/README.md#简体中文)、[预约睡眠](../../../windows-integration/kits/auto-sleep/README.md#简体中文)、[云端已读](../../../windows-integration/kits/cloud-mark-read/README.md#简体中文)和[设置按钮](../manager-entry/README.md#简体中文)分别提供各自的工具栏内容。

需要 Core 0.3.39 或更高版本。Kit 开发者可通过 [Kit API](../../docs/features.md)向 `left`、`center`、`right` 区域添加内容。
