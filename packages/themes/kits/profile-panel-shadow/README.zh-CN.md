# Profile panel shadow

[English](README.md) | 简体中文

为 Codex 主界面的个人资料菜单添加轮廓和阴影，使菜单更容易与侧边栏区分。

在 **插件** 中启用 `profile-panel-shadow`，再点击 **重启插件宿主**。安装 Themes 时，将 `profile-panel-shadow` 加入其 `externalKits` 选项。
