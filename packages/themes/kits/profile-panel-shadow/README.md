# Profile panel shadow

[English](#profile-panel-shadow) | [简体中文](#简体中文)

Adds an outline and shadow to the profile menu in the Codex main interface, making it easier to distinguish from the sidebar.

Enable `profile-panel-shadow` in **Kits** and choose **Restart Kit host**. If Themes is installed, add `profile-panel-shadow` to its `externalKits` option.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

为 Codex 主界面的个人资料菜单添加轮廓和阴影，使菜单更容易与侧边栏区分。

在 **插件** 中启用 `profile-panel-shadow`，再点击 **重启插件宿主**。安装 Themes 时，将 `profile-panel-shadow` 加入其 `externalKits` 选项。
