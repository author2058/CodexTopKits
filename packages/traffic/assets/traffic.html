Attributed by native thread ID; unattributed traffic is listed separately. Sent and received counts are compressed HTTP bodies or WebSocket frames, excluding TLS, TCP, IP, handshake and file API overhead, and do not equal billed network traffic. First image uploads are listed separately and are not counted again in the model channel. JSON sizes describe content, not network traffic. Long connections are included by measurement update time, usually aggregated to one second.
