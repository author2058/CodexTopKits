# 图片与流量覆盖范围

[English](COVERAGE.md) | 简体中文

## 图片生产与消费

| 入口 | 本包提供的能力 | 边界 |
|---|---|---|
| 工具生产观察图 | 公开图片选择器；定性 WebP85、必要时 JPG90，定量 PNG | 生产工具必须实际调用选择器并支持编码；本包不改写所有截图工具 |
| 已有 PNG 供模型定性观察 | 原尺寸 UUID 观察副本，保留原件及来源元数据 | 只处理显式传入的当前文件；不会扫描整个工程 |
| 本机 `view_image` | 原生 PreToolUse Hook 核对文件扩展名和实际编码，记录元数据 | 需要原生信任；不自动转图，不读取远程执行器里的同名路径 |
| 模型请求中的已支持图片容器 | HTTP／WebSocket 中按实际图片内容和账户复用文件引用 | 非公开接线可能随客户端改变；未知容器会明确报错，不静默重复上传 |
| MCP 图片结果、Computer Use、生成图片和其他直接返回图片的工具 | 随包技能提示先核对当前链路的格式能力 | 没有统一的二进制拦截；原生工具不支持编码参数时，本包不能强制其使用 WebP |
| 客户端图片重编码 | 当前机器原生程序的三组回环检查 | 使用合成图，不调用云端模型；模型实际预算不能仅凭长宽比推断 |

技能按任务发现，不等同于每次必然加载。需要强制提醒的工作流可在自己的 AGENTS.md 引用 `codex-bandwidth-images`；安装器不改写已有 AGENTS.md 或信任状态。

## 流量统计

| 来源 | 默认状态 | 可以回答 | 不能回答 |
|---|---|---|---|
| 本包模型代理 | 启用 | 线程／连接的模型传输字节、逻辑大小、首次图片上传和缓存复用 | 代理外流量、TLS／TCP／IP 和完整文件 API 开销、运营商账单 |
| Chromium／CDP | 关闭 | 原有页面、静态资源、遥测、实时连接与可归属请求的分类 | 原生 codex.exe 不经过 Chromium 的传输；部分 worker 来源可能不可见 |
| Windows 内核 ETW | 关闭 | 目标进程树的 TCP／UDP 收发字节和远端端点 | 加密内容、同一原生进程内的具体线程归属；丢事件时不能声称总量完整 |
| Windows 连接快照 | 关闭 | 当前 TCP 连接和 UDP 绑定、进程与端点 | 字节量、短连接的完整历史、连接建立时间 |

这些来源可能观察同一通信，不可相加。页面明确列出未启用、等待、采集缺口和错误；无数据不表示流量为 0。默认不保存提示词、图片正文、认证头、TLS 密钥或完整请求。
