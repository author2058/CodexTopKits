# Selection actions delay

[English](#selection-actions-delay) | [简体中文](#简体中文)

Selection actions delay makes the selected-text action menu appear after a one-second pause and fade in over 500 milliseconds. The menu accepts clicks after the fade completes.

Enable `selection-actions-delay` in **Kits**, then choose **Restart Kit host**. Select text and wait for the action menu to appear.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

选中文本菜单延迟让选中文本后的操作菜单等待一秒，再用 500 毫秒淡入。淡入完成后可以点击菜单。

在 **插件** 中启用 `selection-actions-delay`，再点击 **重启插件宿主**。选中文本后等待操作菜单出现。
