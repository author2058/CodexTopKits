# Context meter

[English](#context-meter) | [简体中文](#简体中文)

Context meter displays Codex's context usage as a thin bar on the composer, with ticks at ten-percent intervals. Its color reflects usage, and the bar turns gray during context compaction.

Enable `context-meter` in **Kits**, then choose **Restart Kit host**. The bar appears when context usage is available. At high usage it flashes, with a faster flash when the composer contains typed text.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

上下文用量条在输入框上显示 Codex 的上下文用量，并以每 10% 为间隔显示刻度。用量条的颜色反映用量，上下文压缩期间显示为灰色。

在 **插件** 中启用 `context-meter`，再点击 **重启插件宿主**。有可用的上下文用量时会显示用量条。用量较高时用量条会闪烁，输入文字后闪烁速度会加快。
