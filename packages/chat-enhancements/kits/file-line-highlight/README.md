# File line highlight

[English](#file-line-highlight) | [简体中文](#简体中文)

File line highlight briefly marks the target line with a blue frame when a file reference in a chat opens a specific line in Codex's editor.

Enable `file-line-highlight` in **Kits**, then choose **Restart Kit host**. Click a file-and-line reference in a chat to see the highlight fade over one second.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

文件行高亮在聊天中的文件引用打开 Codex 编辑器的指定行时，用蓝色边框短暂标记目标行。

在 **插件** 中启用 `file-line-highlight`，再点击 **重启插件宿主**。点击聊天中包含行号的文件引用，高亮会在一秒内淡出。
