# Image viewer close button

[English](#image-viewer-close-button) | [简体中文](#简体中文)

Image viewer close button colors the image preview's close button red, making it easier to find.

Enable `image-viewer-close` in **Kits**, then choose **Restart Kit host**. Open an image preview to see the button.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

图片预览关闭按钮将图片预览窗口的关闭按钮显示为红色，方便辨认。

在 **插件** 中启用 `image-viewer-close`，再点击 **重启插件宿主**。打开图片预览即可看到该按钮。
