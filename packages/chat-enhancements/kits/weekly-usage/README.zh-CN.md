# Weekly usage

[English](README.md) | 简体中文

在 Codex 底栏显示每周剩余额度和重置时间，并用两条进度条展示当前额度周期内的用量和时间。显示内容随 Codex 的用量数据更新；数据就绪前显示等待提示。

在 **插件** 中启用 `weekly-usage` 和依赖的 [footer](../../../core/kits/footer/README.zh-CN.md)，再点击 **重启插件宿主**。如需在时间进度条上显示预计硬重置标记，启用[预约重置标记](../scheduled-reset-marker/README.zh-CN.md)并配置其服务。

需要 Core 0.3.39 或更高版本，以及 0.1 系列中 0.1.1 或更高版本的 `footer`。
