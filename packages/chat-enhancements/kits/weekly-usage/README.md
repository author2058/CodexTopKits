# Weekly usage

[English](#weekly-usage) | [简体中文](#简体中文)

Shows the remaining weekly allowance and reset date in the Codex footer, with tracks for usage and time through the current allowance period. The display follows Codex's usage data and shows a waiting message until that data is available.

## Use

Enable `weekly-usage` and its [footer](../../../core/kits/footer/README.md) dependency in **Kits**, then choose **Restart Kit host**. To add an estimated hard-reset marker to the time track, enable [scheduled reset marker](../scheduled-reset-marker/README.md) and configure its service.

Requires Core 0.3.39 or later and `footer` 0.1.1 or later within the 0.1 series.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

在 Codex 底栏显示每周剩余额度和重置时间，并用两条进度条展示当前额度周期内的用量和时间。显示内容随 Codex 的用量数据更新；数据就绪前显示等待提示。

在 **插件** 中启用 `weekly-usage` 和依赖的 [footer](../../../core/kits/footer/README.md#简体中文)，再点击 **重启插件宿主**。如需在时间进度条上显示预计硬重置标记，启用[预约重置标记](../scheduled-reset-marker/README.md#简体中文)并配置其服务。

需要 Core 0.3.39 或更高版本，以及 0.1 系列中 0.1.1 或更高版本的 `footer`。
