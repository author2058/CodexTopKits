# Composer timer

English | [简体中文](README.zh-CN.md)

Shows Codex's working duration in a bar below the composer and keeps the last duration visible after the turn finishes.

## Use

Configure the `chat-diagnostics` service with module `codex-toolkit-chat/diagnostic-service`. Enable `composer-timer` in **Kits**, then choose **Restart Kit host**. Add [live model output](../live-model-output/README.md) to open the current chat's recent model output from the timer bar.

Requires Core 0.3.39 or later.
