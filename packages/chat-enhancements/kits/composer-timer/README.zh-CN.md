# Composer timer

[English](README.md) | 简体中文

在输入框下方的计时条中显示 Codex 的工作时长，并在本轮结束后保留最近一次时长。

将 `chat-diagnostics` 服务的模块配置为 `codex-toolkit-chat/diagnostic-service`。在 **插件** 中启用 `composer-timer`，再点击 **重启插件宿主**。启用[实时模型输出](../live-model-output/README.zh-CN.md)后，可从计时条打开当前聊天的近期模型输出。

需要 Core 0.3.39 或更高版本。
