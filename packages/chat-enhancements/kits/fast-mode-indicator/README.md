# Fast mode indicator

English | [简体中文](README.zh-CN.md)

Fast mode indicator highlights the fast-mode icon and displays a lightning symbol beside the composer when the current chat uses fast mode.

Enable `fast-mode-indicator` in **Kits**, then choose **Restart Kit host**. The Kit requires Core 0.3.39 or later.
