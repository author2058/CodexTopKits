# Scroll handoff fix

English | [简体中文](README.zh-CN.md)

Helps preserve the reading position when Codex replaces a conversation's transcript layout.

Configure the `chat-diagnostics` service with module `codex-toolkit-chat/diagnostic-service`. Enable `scroll-handoff-fix` in **Kits**, then choose **Restart Kit host**. The Kit works automatically while reading a conversation. Requires Core 0.3.23 or later.
