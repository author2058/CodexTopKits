# Scroll handoff fix

[English](README.md) | 简体中文

在 Codex 替换聊天内容布局时，帮助保持当前阅读位置。

将 `chat-diagnostics` 服务的模块配置为 `codex-toolkit-chat/diagnostic-service`。在 **插件** 中启用 `scroll-handoff-fix`，再点击 **重启插件宿主**。阅读聊天时，Kit 会自动运行。需要 Core 0.3.23 或更高版本。
