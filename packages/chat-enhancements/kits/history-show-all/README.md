# Show all history

English | [简体中文](README.zh-CN.md)

Adds a **Show all** button to expanded turns with older output available to load. Select it to load all history items for that turn; the button disappears when the turn is fully loaded.

Enable `history-show-all` in **Kits**, then choose **Restart Kit host**. Requires Core 0.3.39 or later.
