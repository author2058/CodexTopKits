# Child model warning

English | [简体中文](README.zh-CN.md)

Child model warning highlights a side chat or subagent composer when its model and reasoning effort match its parent chat.

Enable `child-model-warning` in **Kits**, then choose **Restart Kit host**. Open a side chat or subagent to see the highlight when the selections match.
