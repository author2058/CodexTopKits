# Table style

[English](#table-style) | [简体中文](#简体中文)

Table style makes tables in assistant messages use the surrounding Markdown font size and adds borders between rows and columns.

Enable `table-style` in **Kits**, then choose **Restart Kit host**. The styling appears automatically on assistant-message tables.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

表格样式让助手消息中的表格使用正文的 Markdown 字号，并在行列之间添加边框。

在 **插件** 中启用 `table-style`，再点击 **重启插件宿主**。助手消息中的表格会自动应用该样式。
