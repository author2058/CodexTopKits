# Title emoji

[English](#title-emoji) | [简体中文](#简体中文)

Title emoji displays the first emoji in the current chat title beside the composer.

Enable `title-emoji` in **Kits**, then choose **Restart Kit host**. Add an emoji to a chat title to see it beside the composer.

[Get started](../../../../docs/getting-started.md) · [All Kits](../../../../README.md#kits)

## 简体中文

标题表情在输入框旁显示当前聊天标题中的第一个表情符号。

在 **插件** 中启用 `title-emoji`，再点击 **重启插件宿主**。在聊天标题中添加表情符号，即可在输入框旁看到它。
